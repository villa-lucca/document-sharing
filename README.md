# Document Sharing

> A simple home for sharing documents with the people who need them.

Document Sharing is the starting point for a lightweight, easy-to-use document-sharing application. The project is currently in its initial setup phase and will evolve as the product is defined and built.

## Project status

🚧 **Early development** — the repository currently contains the project scaffold only.

## Vision

The goal is to make sharing documents straightforward, with a focused experience for:

- uploading and organizing documents;
- sharing documents through simple, controlled access; and
- helping recipients find what they need quickly.

## Getting started

Clone the repository:

```bash
git clone https://github.com/villa-lucca/document-sharing.git
cd document-sharing
```

Implementation and development instructions will be added as the application takes shape.
